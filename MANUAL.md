# Bot A — инструкция по управлению

Простыми словами: как запустить, как остановить, где смотреть графики и что означают
кнопки-флаги. Все команды выполняются из папки проекта.

---

## 0. Что где лежит

| Что | Где |
|---|---|
| Токен T-Invest | `secrets\tinvest_token.txt` (или переменная `$env:TINVEST_TOKEN`) |
| Настройки пар | `appsettings.json` |
| Логи | `logs\bot_a.log`, `logs\multi_v262.log` |
| Графики | `reports\charts\<имя_прогона>\index.html` |
| Отчёты | `reports\*.md` |
| След дня (Z, сделки) | `state\watch_<пара>_<дата>.jsonl` |

## 1. Три способа включить бота

### 1.1. Живой стакан одной пары (без денег)

```powershell
py -3 -m bot_a --mode watch --preset VTBR_SBER --port 8099 --record-interval-ms 400
```

Открыть в браузере: **http://127.0.0.1:8099/**

Режим «подглядывания»: реальный стакан с биржи, сделки считает симулятор, деньги не тратятся.

### 1.2. Весь портфель сразу (5 пар)

```powershell
py -3 -m bot_a --mode watch --preset ALL_ACTIVE --port 8099 --record-interval-ms 400
```

Та же ссылка — вместо стаканов таблица всех пар: `Z`, сколько σ осталось до входа, `σ/Fee`,
дрейф беты, сделки, профит.

> `--record-interval-ms` — как часто спрашивать биржу. **400–600 мс** безопасно. При 150–200 мс
> на 5 парах биржа отвечает «429» (слишком часто) — бот не сломается, но данных будет меньше.

### 1.3. История + красивые графики (тоже без денег)

```powershell
py -3 -m bot_a --mode backtest --preset VTBR_SBER --source iss --days 30 --charts
```

Путь к папке с графиками печатается в конце. Открыть:

```powershell
start reports\charts\<имя_папки>\index.html
```

## 2. Как остановить

| Способ | Как | Что будет |
|---|---|---|
| Обычный | `Ctrl + C` в том же окне | аккуратно завершится, закроет позицию, сохранит отчёт |
| По таймеру | добавить `--duration 3600` (1 час) | остановится сам |
| Аварийный | в другом окне: `Get-Process python \| Select Id`, затем `Stop-Process -Id 12345` | жёстко, отчёт не сохранится |

Без `--duration` бот работает до `Ctrl+C`. Флаг `--no-flatten` оставляет позицию открытой
при остановке.

## 3. Где смотреть графики

### 3.1. Живой график (во время `--mode watch`)

Строится прямо в браузере, файлы не создаются. На странице:

- **стакан** обеих ног пары с подсветкой объёма;
- **Z-score** крупными цифрами + шкала-спидометр с зонами входа;
- **график Z во всю ширину** — линия Z, зоны ±`Z_entry`, зелёные точки = моменты, когда бот должен войти;
- **«Условия входа сейчас»** — чек-лист 8 фильтров: зелёное выполнено, красное мешает;
- **«Сделки бота»** — вход, выход, цена, причина, минуты в позиции, профит;
- **«Лента сделок»** — реальные принты с биржи.

### 3.2. Графики после прогона (`--mode paper` или `--mode backtest --charts`)

Папка `reports\charts\<имя_прогона>\`:

| Файл | Что показывает |
|---|---|
| `index.html` | **открывать этот** — все графики на одной странице |
| `01_overview.png` | Z-score + обе ноги + стрелки входов (▲/▼) и выходов (×) |
| `02_equity.png` | кривая капитала (сколько бы заработал) |
| `03_daily_pnl.png` | прибыль по дням столбиками |
| `04_trades_and_exits.png` | разбор каждой сделки: вход, выход, тейк/стоп |
| `05_zoom_*.png` | крупный план сделок (свечи + точки входа/выхода) |
| `trades.csv` | таблица сделок, открывается в Excel |

Больше крупных планов: `--charts --chart-trades 10`.

## 4. Основные элементы управления

### Режимы (`--mode`)

| Режим | Что делает | Нужен токен |
|---|---|---|
| `watch` | смотреть живой стакан + график в браузере | да |
| `paper` | торговать на живых данных симулятором + графики | да (или `--source iss` — тогда нет) |
| `live` | **реальные деньги** (дополнительно требует `--yes`) | да |
| `backtest` | прогон истории | нет (`--source iss`) |
| `optimize` | перебор параметров | нет |
| `record` | записать стакан в файл для будущих тестов | да |
| `preflight` | проверить счёт, права, маржу | да |

### Настройки

| Флаг | Смысл | Типичное значение |
|---|---|---|
| `--preset` | пара: `VTBR_SBER`, `MTLR_SBER`, `AFKS_SBER`, `IRAO_SBER`, `SPZ6_SRZ6` или `ALL_ACTIVE` | `ALL_ACTIVE` |
| `--port` | порт дашборда | `8099` |
| `--duration` | сколько секунд работать | `3600` = 1 час |
| `--record-interval-ms` | частота опроса биржи, мс | `400` |
| `--tariff` | `Premium` (дешевле) или `Trader` | `Premium` |
| `--days` | глубина истории для бэктеста | `30` |
| `--charts` | сохранить PNG + HTML (для `backtest`) | — |
| `--chart-dir` | своя папка для графиков | `reports\charts\моё` |
| `--report-stem` | своё имя прогона | `тест1` |
| `--log-level Debug` | подробный лог | — |

### Проверка перед стартом

```powershell
py -3 -m bot_a --mode preflight --monday-ready
```

Таблица: токен, счёт, права, метаданные инструментов, торговый статус, ГО, окна входа.
В конце — «ИТОГ: ГОТОВ К РАБОТЕ» либо что именно не так.

## 5. Как понять, что бот собирается войти

Панель «Условия входа сейчас» — 8 фильтров:

| Фильтр | Что значит |
|---|---|
| `z` | \|Z\| дошёл до порога (2.8) |
| `hook` | Z развернулся после пика — без него вход не будет |
| `regime` | ноги не двигаются синхронно (иначе это тренд, а не арбитраж) |
| `obi` | перевес в стакане на нашей стороне |
| `vol` | волатильность покрывает комиссию (`σ/Fee ≥ 1.30`) |
| `edge` | ожидаемый возврат больше комиссии + проскальзывания |
| `window` | мы внутри окна входа (10:05–12:30, 15:30–18:35 МСК) |
| `daily` | дневной предохранитель не сработал |

Под чек-листом написано, что именно мешает, например: «нет подтверждения разворота (хук пика Z)».

### «Почему сегодня не было сделок?»

```powershell
py -3 scripts/z_diagnostics.py --date 2026-10-27
```

Показывает максимум |Z| за день, часы, когда сигнал подходил близко, и какой фильтр отсёк вход.

## 6. Частые вопросы

**Не вижу стакана / страница пустая.** Порт в команде и в браузере должен совпадать.
Порт занят? Возьми `--port 8098`.

**В колонке «ошибки» красное число.** Это `HTTP 429`: биржа просит опрашивать реже.
Подними `--record-interval-ms` до 600. Бот сам выдерживает паузу и продолжает.

**`σ/Fee` красное.** Порог 1.30 не выполнен — волатильность мала относительно комиссии.
Это правильный отказ: сделка была бы убыточной. Ждать.

**Мало сделок.** Портфель рассчитан на 4–8 сделок в день суммарно; одна пара даёт 1–2.

**Компьютер тормозит.** Не ставь `--jobs` больше 2. Скрипты расчётов по умолчанию работают
в 1–2 процесса и грузят машину не более чем на ~20 %.

**Два бота одновременно.** Можно, но на разных портах (`--port 8099` и `--port 8098`).
Тяжёлый грид параллельно с живым дашбордом не запускать.

## 7. Шпаргалка

```powershell
# Проверить готовность
py -3 -m bot_a --mode preflight --monday-ready

# Смотреть весь портфель 8 часов
py -3 -m bot_a --mode watch --preset ALL_ACTIVE --port 8099 --record-interval-ms 400 --duration 28800

# Смотреть одну пару с графиком входа
py -3 -m bot_a --mode watch --preset VTBR_SBER --port 8099 --record-interval-ms 400

# Торговать виртуально 1 час + графики после закрытия
py -3 -m bot_a --mode paper --preset ALL_ACTIVE --duration 3600 --record-interval-ms 400

# Прогнать историю 30 дней с графиками
py -3 -m bot_a --mode backtest --preset VTBR_SBER --source iss --days 30 --charts

# Разобрать день без сделок
py -3 scripts/z_diagnostics.py --date 2026-10-27

# Открыть папку с графиками
start reports\charts
```
