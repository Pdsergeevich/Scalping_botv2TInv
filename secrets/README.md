# Токен T-Invest для Bot A

Положите сюда файл `tinvest_token.txt` с токеном (одна строка, без кавычек).
Файл читается автоматически; в чат и в логи токен не попадает.

Альтернативы:
* переменная окружения `TINVEST_TOKEN` в том же процессе, что запускает бота;
* `TINVEST_TOKEN_FILE=/путь/к/файлу`;
* флаг `--token ...` (не рекомендуется: остаётся в истории shell).

Команда для записи (в вашем терминале, токен в историю не попадёт):

    Set-Content -Path secrets\tinvest_token.txt -Value $env:TINVEST_TOKEN -NoNewline

Проверка источника без раскрытия значения:

    py -3 -m bot_a --mode preflight
